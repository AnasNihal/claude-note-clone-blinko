# 🚀 Blinko - Ultimate Easy Setup

## 🎯 ONE CLICK SETUP - ZERO CONFIGURATION

This is the **easiest way to run Blinko** on any computer. No technical knowledge required!

---

## 🖥️ For Windows Users
**Double-click this file:** `START-WINDOWS.bat`

That's it! Everything will be setup automatically.

---

## 🍎 For Mac/Linux Users  
**Run this command:** `./START-MAC-LINUX.sh`

Or double-click the file and select "Run in Terminal"

---

## ✅ What Happens Automatically

1. **Docker Check** - Verifies Docker is installed and running
2. **Environment Setup** - Creates all required configuration files
3. **Database** - Starts PostgreSQL database automatically
4. **Network Setup** - Configures Docker networking
5. **Build Application** - Builds Blinko from source code
6. **Start Services** - Launches everything needed
7. **Open Browser** - Automatically opens Blinko in your browser
8. **AI Features** - Pre-configured and ready to use

## 🎮 Requirements

**Only ONE thing needed:** Docker Desktop installed

- **Windows:** Download from https://docker.com
- **Mac:** Download from https://docker.com  
- **Linux:** Install via your package manager

That's it! No other dependencies required.

---

## 📱 First Time Setup

1. Install Docker Desktop (if not already installed)
2. Double-click the appropriate start file for your OS
3. Wait for setup to complete (2-5 minutes)
4. Blinko opens automatically in your browser

---

## 🔧 For Production Use

The demo setup includes sample API keys. For real AI features:

1. Open the `.env` file (created automatically)
2. Replace demo keys with your actual API keys:
   - OpenAI: Get from https://platform.openai.com
   - Anthropic: Get from https://console.anthropic.com  
   - Google AI: Get from https://makersuite.google.com
3. Restart: Double-click the start file again

---

## 🆘 Troubleshooting

**"Docker not found"** → Install Docker Desktop first

**"Docker not running"** → Start Docker Desktop and wait 2 minutes

**"Port already in use"** → Restart your computer, then try again

**"Build failed"** → Check internet connection, try again

---

## 📁 Files You Can Ignore

- `.env.example` - Template file (don't edit)
- `dockerfile` - Build configuration (don't edit)  
- `local-install.sh` - Advanced setup (use START files instead)
